Iris Flower Classification 🌸

Project Overview

Iris Flower Classification is a Machine Learning project that predicts the species of an iris flower based on its physical measurements.

The model classifies flowers into three species:

- Setosa
- Versicolor
- Virginica

Objective

The main objective of this project is to build and evaluate Machine Learning classification models to accurately identify iris flower species using the given dataset.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- VS Code

Dataset

The Iris dataset contains 150 samples with four important features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable represents the three iris flower species.

Project Workflow

1. Import required Python libraries.
2. Load the Iris dataset.
3. Perform Exploratory Data Analysis (EDA).
4. Visualize the dataset using graphs.
5. Split the dataset into training and testing sets.
6. Train Machine Learning classification models.
7. Evaluate model performance.
8. Identify the best-performing model.

Machine Learning Models

The project uses classification algorithms to predict iris flower species.

Results

The trained models are evaluated using accuracy, confusion matrix, precision, recall and F1-score to compare their performance.

Conclusion

This project demonstrates how Machine Learning can be used for classification problems. It provides practical experience in data analysis, visualization, model training and evaluation.
