
# Unemployment Analysis with Python

## Internship
Oasis Infobyte Data Science Internship

## Project Overview
This project analyzes unemployment trends in India using Python. It explores unemployment rates across different states, monthly trends, employment patterns, and the changes observed during the COVID-19 period.

## Dataset
Unemployment in India dataset.

The dataset contains information about:
- Region
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data cleaning and preprocessing
- Statistical analysis of unemployment rates
- State-wise unemployment analysis
- Monthly unemployment trends
- Employment analysis by state
- Pre-COVID and COVID-period comparison
- Unemployment distribution visualization
- Correlation heatmap
- Top 10 states with highest average unemployment

## Key Findings
- Total records analyzed: 740
- Number of states: 28
- Overall average unemployment rate: 11.79%
- Highest average unemployment: Tripura
- Lowest average unemployment: Meghalaya
- Pre-COVID average: 9.51%
- March 2020 onward average: 17.77%

## Conclusion
The project highlights regional differences in unemployment across India and shows an increase in the average unemployment rate from March 2020 onward compared with the pre-COVID period.
