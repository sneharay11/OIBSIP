# Task 1: Landing Page — TechNova

## About the Project
TechNova is a fictional technology brand landing page created as part of the Oasis Infobyte Web Development & Designing internship.

The project demonstrates foundational HTML5 and CSS3 skills through a clean, responsive website layout.

## Features
- Navigation bar with Home, Features, About, and Contact links
- Hero section with a headline, subtitle, and call-to-action button
- Features section with three content cards
- About and Contact sections
- Footer with navigation and contact links
- Consistent colour palette and typography
- Responsive layout for desktop and mobile screens
- Smooth scrolling and hover effects

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Ensure `style.css` remains in the same project folder.
