
# Car Price Prediction with Machine Learning

## Internship
Oasis Infobyte Data Science Internship

## Project Overview
This project predicts the selling price of used cars using machine learning regression models. It uses features such as car brand, age, mileage, fuel type, transmission, and present price.

## Dataset
Vehicle Dataset from CarDekho.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Dataset loading and inspection
2. Data cleaning and preprocessing
3. Feature engineering (car age and brand extraction)
4. Exploratory Data Analysis
5. Categorical variable encoding
6. Feature correlation heatmap
7. Train-test splitting
8. Linear Regression model training
9. Random Forest Regression model training
10. Model evaluation using MAE, RMSE and R²
11. Actual vs predicted price visualization
12. Feature importance analysis

## Models Used
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion
The project compares two regression models to identify the better-performing model for predicting used car prices. Feature importance analysis helps understand which factors influence car selling prices.
